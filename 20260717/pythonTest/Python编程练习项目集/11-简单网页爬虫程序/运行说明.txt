# 11-简单网页爬虫程序

## 功能简介

一个简单的网页爬虫，使用 Python 标准库 `urllib` 和 `html.parser` 抓取网页并提取标题、链接与标题标签。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `网页爬虫.py` | 主程序源代码与命令行入口 |
| `测试_网页爬虫.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 抓取示例网站（请替换为实际可访问的 URL）
python 网页爬虫.py https://example.com

# 指定超时时间
python 网页爬虫.py https://example.com --timeout 15
```

## 注意事项

- 请遵守目标网站的 `robots.txt` 和使用条款
- 频繁抓取可能触发反爬机制，请合理设置请求间隔
- 本程序仅供学习交流使用

## 扩展建议

- 增加请求头伪装与 Cookie 支持
- 支持递归抓取站内链接
- 将结果保存到文件或数据库
