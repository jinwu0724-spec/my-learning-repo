# 09-学生成绩管理系统

## 功能简介

管理学生信息及各科成绩，支持平均分计算、排名生成和 CSV 导出，数据持久化保存到 JSON 文件。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `学生成绩管理.py` | 主程序源代码与命令行入口 |
| `测试_学生成绩管理.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 添加学生
python 学生成绩管理.py add 2024001 张三

# 录入成绩
python 学生成绩管理.py score 2024001 数学 90

# 查看平均分
python 学生成绩管理.py average 2024001

# 查看排名
python 学生成绩管理.py rank

# 导出 CSV
python 学生成绩管理.py export 成绩表.csv
```
