# 01-基础计算器应用

## 功能简介

一个支持加、减、乘、除、括号优先级以及幂运算的安全计算器。表达式通过 Python 标准库 `ast` 进行解析，不使用 `eval`，避免代码注入风险。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `基础计算器.py` | 主程序源代码，包含 `Calculator` 类与命令行交互入口 |
| `测试_基础计算器.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

### 1. 命令行交互模式

```bash
python 基础计算器.py
```

输入数学表达式后按回车即可查看结果，输入 `quit` 或 `exit` 退出。

### 2. 作为模块调用

```python
from 基础计算器 import Calculator

calc = Calculator()
print(calc.evaluate("(1 + 2) * 3"))  # 输出: 9
```

### 3. 运行测试

```bash
python -m unittest 测试_基础计算器.py
```
