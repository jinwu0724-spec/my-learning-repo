# 10-简易日志分析工具

## 功能简介

解析统一格式的日志文件，支持按日志级别统计、关键字搜索和按时间范围过滤。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `日志分析工具.py` | 主程序源代码与命令行入口 |
| `测试_日志分析工具.py` | 单元测试文件 |
| `示例日志.log` | 示例日志数据 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 统计各级别日志数量
python 日志分析工具.py count 示例日志.log

# 搜索包含“超时”的日志
python 日志分析工具.py search 示例日志.log 超时

# 按时间范围过滤
python 日志分析工具.py filter 示例日志.log "2024-05-20 08:30:00" "2024-05-20 08:35:00"
```
