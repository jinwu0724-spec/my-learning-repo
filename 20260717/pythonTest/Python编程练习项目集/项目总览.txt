# Python 编程练习项目集

本目录包含 11 个精心设计的 Python 练习项目，涵盖基础语法、文件操作、数据结构、命令行工具、网络爬虫等常见编程场景。所有文件均采用中文命名，便于学习和查阅。

| 02 | 02-猜数字游戏 | 随机数猜测小游戏，限定猜测次数 |

## 统一运行测试

进入任意项目目录后执行：

```bash
python -m unittest 测试_*.py
```

或在项目集根目录运行以下命令批量测试所有项目：

```powershell
$base = "Python编程练习项目集"
Get-ChildItem -Path $base -Recurse -Filter "测试_*.py" | ForEach-Object {
    Set-Location $_.DirectoryName
    python -m unittest $_.Name
}
```

## 目录结构规范

每个项目目录通常包含：

- 主程序源代码文件（`.py`）
- 单元测试文件（`测试_*.py`）
- 运行说明文档（`运行说明.txt`）
- 部分项目附带示例数据文件
