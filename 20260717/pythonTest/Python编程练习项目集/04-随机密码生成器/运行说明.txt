# 04-随机密码生成器

## 功能简介

根据用户配置生成安全的随机密码，支持大写字母、小写字母、数字和特殊符号的灵活组合。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `随机密码生成器.py` | 主程序源代码与命令行入口 |
| `测试_随机密码生成器.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 生成默认 12 位密码
python 随机密码生成器.py

# 生成 16 位仅包含大小写字母和数字的密码
python 随机密码生成器.py -l 16 --no-symbols
```

## 扩展建议

- 增加密码强度评估
- 将生成的密码保存到加密文件或密码管理器
- 支持排除容易混淆的字符（如 0 和 O）
