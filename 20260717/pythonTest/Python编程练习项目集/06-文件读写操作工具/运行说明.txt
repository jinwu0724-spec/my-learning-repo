# 06-文件读写操作工具

## 功能简介

提供常用文件操作功能，包括读取、写入、追加、复制、统计行数、搜索关键字和列示目录。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `文件读写工具.py` | 主程序源代码与命令行入口 |
| `测试_文件读写工具.py` | 单元测试文件 |
| `示例数据.txt` | 示例文本数据 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 读取文件
python 文件读写工具.py read 示例数据.txt

# 写入文件（覆盖）
python 文件读写工具.py write 新文件.txt "Hello 世界"

# 追加内容
python 文件读写工具.py append 新文件.txt "追加一行"

# 复制文件
python 文件读写工具.py copy 示例数据.txt 数据备份.txt

# 统计行数
python 文件读写工具.py count 示例数据.txt

# 搜索关键字
python 文件读写工具.py search 示例数据.txt 示例

# 列示目录
python 文件读写工具.py list --dir .
```

## 扩展建议

- 支持二进制文件读写
- 增加文件编码自动检测
- 支持正则表达式搜索
