# 02-猜数字游戏

## 功能简介

经典的猜数字小游戏。程序随机生成一个 1 到 100 之间的整数，玩家需要在限定次数内猜中。每次猜测后，程序会提示“偏大”、“偏小”或“猜中”。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `猜数字游戏.py` | 主程序源代码，包含 `GuessNumberGame` 类与命令行交互入口 |
| `测试_猜数字游戏.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

### 1. 命令行交互模式

```bash
python 猜数字游戏.py
```

根据提示输入整数即可开始游戏。

### 2. 作为模块调用

```python
from 猜数字游戏 import GuessNumberGame

game = GuessNumberGame(1, 100, 7)
game.start(seed=42)
print(game.check_guess(50))
```

### 3. 运行测试

```bash
python -m unittest 测试_猜数字游戏.py
```
