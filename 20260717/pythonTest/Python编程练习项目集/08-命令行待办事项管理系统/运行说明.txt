# 08-命令行待办事项管理系统

## 功能简介

一个命令行待办事项管理工具，支持添加、完成、删除、筛选和清空事项，数据持久化保存到 JSON 文件。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `待办事项管理.py` | 主程序源代码与命令行入口 |
| `测试_待办事项管理.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 添加待办事项
python 待办事项管理.py add "学习 Python"

# 列示所有事项
python 待办事项管理.py list

# 按状态筛选
python 待办事项管理.py list --status 待完成

# 标记完成
python 待办事项管理.py complete 1

# 删除事项
python 待办事项管理.py remove 1

# 清空所有事项
python 待办事项管理.py clear
```
