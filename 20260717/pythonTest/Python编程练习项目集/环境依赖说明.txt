# 环境依赖说明

## 运行环境

- Python 版本：Python 3.10 或更高版本
- 操作系统：Windows、macOS、Linux 均可

## 第三方依赖

本练习项目集完全基于 Python 标准库实现，无需安装任何第三方包。

## 验证 Python 版本

在终端中运行以下命令：

```bash
python --version
```

建议输出为 `Python 3.10.x` 或更高版本。

## 运行方式

进入任意项目目录后，根据该项目 `运行说明.txt` 中的指引执行对应命令即可。

## 编码说明

所有源代码文件均采用 UTF-8 编码，并已声明 `# -*- coding: utf-8 -*-`。在 Windows 命令行中如出现中文乱码，可尝试将终端编码设置为 UTF-8：

```powershell
chcp 65001
```
