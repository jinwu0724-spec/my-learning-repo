# 05-单位换算工具

## 功能简介

支持长度、重量和温度三类常用单位的相互换算，便于日常计算和学习使用。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `单位换算工具.py` | 主程序源代码与命令行交互入口 |
| `测试_单位换算工具.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
python 单位换算工具.py
```

按提示输入：类别 数值 原单位 目标单位，例如 `长度 100 厘米 米`。

## 扩展建议

- 增加面积、体积、货币等单位换算
