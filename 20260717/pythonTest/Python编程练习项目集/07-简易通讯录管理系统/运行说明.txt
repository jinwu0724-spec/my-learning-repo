# 07-简易通讯录管理系统

## 功能简介

一个基于 JSON 文件持久化的通讯录管理系统，支持联系人的增删改查和关键字搜索。

## 文件说明

| 文件名 | 说明 |
| --- | --- |
| `通讯录管理.py` | 主程序源代码与命令行入口 |
| `测试_通讯录管理.py` | 单元测试文件 |
| `运行说明.txt` | 本说明文档 |

## 运行方式

```bash
# 添加联系人
python 通讯录管理.py add 张三 13800138000 zhangsan@example.com

# 列示联系人
python 通讯录管理.py list

# 搜索联系人
python 通讯录管理.py search 张三

# 更新联系人
python 通讯录管理.py update 张三 --phone 13900139000

# 删除联系人
python 通讯录管理.py delete 张三
```
