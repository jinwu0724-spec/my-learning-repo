## 第1讲 随机事件与概率

**核心：研究 P(A)**

### 基本概念
- **随机试验**：可重复、结果不止一个、事先不确定
- **样本空间 Ω**：所有可能结果的集合
- **随机事件**：Ω 的子集，`A ⊆ Ω`

### 事件的关系与运算
- **关系**：包含 ⊆、相等 =、交 ∩、并 ∪、差 −、互斥（`AB=∅`）、对立（`Ā = Ω−A`）
- **运算律**：交换律、结合律、分配律、**对偶律（De Morgan）**：
  - `Ā∪B̄ = A̅ ∩ B̅`
  - `Ā∩B̄ = A̅ ∪ B̅`

### 概率的定义
- **古典概型**：有限等可能，`P(A) = |A| / |Ω|`
- **几何概型**：`P(A) = μ(A) / μ(Ω)`（长度/面积/体积比）
- **公理化定义**：非负性、规范性、可列可加性

### 核心公式（★必考）

| 公式 | 表达式 |
|------|--------|
| 加法公式 | `P(A∪B) = P(A) + P(B) − P(AB)` |
| 减法公式 | `P(A−B) = P(A) − P(AB)` |
| 条件概率 | `P(B\|A) = P(AB) / P(A)` |
| 乘法公式 | `P(AB) = P(A)·P(B\|A)` |
| **全概率公式** | `P(B) = Σ P(Aᵢ)·P(B\|Aᵢ)`（Aᵢ 为 Ω 的划分） |
| **贝叶斯公式** | `P(Aⱼ\|B) = P(Aⱼ)P(B\|Aⱼ) / Σ P(Aᵢ)P(B\|Aᵢ)` |

### 事件的独立性
- **定义**：`P(AB) = P(A)P(B)` ⇔ A 与 B 独立
- **性质**：A,B 独立 ⇒ A,B̄ 独立；Ā,B 独立；Ā,B̄ 独立
- **n 重伯努利试验**：`P(X=k) = C(n,k) pᵏ(1−p)ⁿ⁻ᵏ`

> **核心思想：全集分解** — 找划分 {Aᵢ}，用全概率 / 贝叶斯拆解复杂事件

## 第2讲 一维随机变量及其分布

**分布函数**：`F(x) = P(X ≤ x)`（右连续，单调不减，`F(−∞)=0, F(+∞)=1`）

### 常见分布速查

| 分布 | 记号 | 分布律/密度 | 参数范围 |
|------|------|------------|----------|
| 0-1 分布 | `B(1,p)` | `P(X=1)=p` | `0<p<1` |
| 二项分布 | `B(n,p)` | `P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ` | `n≥1, 0<p<1` |
| 泊松分布 | `P(λ)` | `P(X=k)=λᵏe⁻λ/k!` | `λ>0` |
| 均匀分布 | `U(a,b)` | `f(x)=1/(b−a)` | `a<b` |
| 指数分布 | `E(λ)` | `f(x)=λe⁻λˣ` (x>0) | `λ>0` |
| 正态分布 | `N(μ,σ²)` | `f(x)=exp(−(x−μ)²/2σ²)/√(2π)σ` | `σ>0` |

### 正态分布要点
- 标准正态 `N(0,1)`：密度 `φ(x)`，分布 `Φ(x)`
- `Φ(0)=1/2`，`Φ(−x)=1−Φ(x)`
- **标准化**：`X~N(μ,σ²)` ⇒ `F(x)=Φ((x−μ)/σ)`
- **线性变换**：`aX+b ~ N(aμ+b, a²σ²)`
- 上侧 α 分位数 `z_α`：`P(X > z_α) = α`

### 指数分布的无记忆性
`P(X > s+t | X > s) = P(X > t) = e^{−λt}`

### 一维随机变量函数的分布

| 类型 | 方法 |
|------|------|
| 离散→离散 | 合并 Y=g(X) 相同值的概率 |
| 连续→连续 | ① **分布函数法**（万能）：`F_Y(y)=P(g(X)≤y)`，再求导得密度 |
| | ② **公式法**（g 严格单调可导时）：`f_Y(y)=f_X(h(y))·|h'(y)|`，`h=g⁻¹` |

> **例**：`X~N(0,1), Y=X²`，用分布函数法：`F_Y(y)=Φ(√y)−Φ(−√y)=2Φ(√y)−1`，求导得 `Y~χ²(1)`

## 第3讲 多维随机变量及其分布

### 联合 / 边缘 / 条件

- **边缘分布函数**：`F_X(x) = F(x, +∞)`，`F_Y(y) = F(+∞, y)`
- **边缘密度**：`f_X(x) = ∫ f(x,y) dy`
- **独立性**：`F(x,y)=F_X(x)F_Y(y)` 或 `f(x,y)=f_X(x)f_Y(y)` 或 `P(X=x,Y=y)=P(X=x)P(Y=y)`
- **条件密度**：`f_{Y|X}(y|x) = f(x,y) / f_X(x)`

### 多维函数的分布（★重点）

| 函数 | 方法 |
|------|------|
| `Z=X+Y` | **卷积公式**：`f_Z(z)=∫ f(x,z−x)dx`（独立时）；或分布函数法分区域积分 |
| `Z=max{X,Y}` | `F_Z(z)=F(z,z)`；独立时 `F_Z(z)=F_X(z)F_Y(z)` |
| `Z=min{X,Y}` | `F_Z(z)=F_X(z)+F_Y(z)−F(z,z)` |
| `Z=X/Y, Z=XY` | 分布函数法分区域积分 |
| `(U,V)=T(X,Y)` | **变换法**：雅可比行列式 `f_UV(u,v)=f_XY(x,y)·|J|⁻¹` |

### 可加性（独立同型分布之和）

| 分布 | 可加性 |
|------|--------|
| 二项 | `X~B(n₁,p), Y~B(n₂,p)` 独立 ⇒ `X+Y~B(n₁+n₂, p)` |
| 泊松 | `X~P(λ₁), Y~P(λ₂)` 独立 ⇒ `X+Y~P(λ₁+λ₂)` |
| 正态 | `X~N(μ₁,σ₁²), Y~N(μ₂,σ₂²)` 独立 ⇒ `X+Y~N(μ₁+μ₂, σ₁²+σ₂²)` |
| χ² | `X~χ²(n₁), Y~χ²(n₂)` 独立 ⇒ `X+Y~χ²(n₁+n₂)` |

## 第4讲 随机变量的数字特征

### 数学期望

- **离散**：`E(X) = Σ x_k · p_k`
- **连续**：`E(X) = ∫ x f(x) dx`
- **函数期望**：`E(g(X)) = ∫ g(x) f(x) dx`（无需先求 g(X) 的分布）
- **多维**：`E(g(X,Y)) = ∫∫ g(x,y) f(x,y) dxdy`

**性质**：线性 `E(aX+bY+c)=aE(X)+bE(Y)+c`；独立时 `E(XY)=E(X)E(Y)`

### 方差

- `Var(X) = E[(X−E(X))²] = E(X²) − E²(X)`
- `Var(aX+b) = a² Var(X)`
- 独立时 `Var(X±Y) = Var(X) + Var(Y)`

### 协方差与相关系数

- **协方差**：`Cov(X,Y) = E[(X−EX)(Y−EY)] = E(XY) − E(X)E(Y)`
- **相关系数**：`ρ_XY = Cov(X,Y) / √(Var(X)Var(Y))`，`|ρ| ≤ 1`
- `|ρ|=1` ⇔ X 与 Y 以概率 1 线性相关：`P(Y=aX+b)=1`
- `ρ=0` ⇔ X 与 Y **不相关**（独立 ⇒ 不相关，反之不然；**正态分布例外：独立⇔不相关**）

### 条件数学期望（近年热门）

- `E(X|Y=y) = ∫ x f_{X|Y}(x|y) dx`（是 y 的函数）
- **重期望公式**：`E(X) = E[E(X|Y)]`
- **条件方差公式**：`Var(X) = Var[E(X|Y)] + E[Var(X|Y)]`

> **例**：`X~N(0,1), Y|X~N(X,1)`，则 `E(Y)=E[E(Y|X)]=E(X)=0`，`Var(Y)=Var(E[Y|X])+E(Var[Y|X])=Var(X)+1=2`

## 第5讲 大数定律与中心极限定理

**研究当 n→∞ 时的极限行为，沟通概率论与数理统计**

### 大数定律（均值收敛到期望）

| 定律 | 条件 | 结论 |
|------|------|------|
| **切比雪夫** | 独立，方差有界 | `(1/n)ΣXᵢ →ᴾ (1/n)ΣE(Xᵢ)` |
| **伯努利** | n 重伯努利试验 | 频率 `n_A/n →ᴾ p` |
| **辛钦** | 独立同分布，E(X)=μ 存在 | `(1/n)ΣXᵢ →ᴾ μ`（不要求方差存在） |

### 中心极限定理（标准化和收敛到正态）

| 定理 | 条件 | 结论 |
|------|------|------|
| **林德伯格-莱维** | 独立同分布，E(X)=μ, Var(X)=σ²>0 | `(ΣXᵢ−nμ)/√(n)σ →ᵈ N(0,1)` |
| **棣莫弗-拉普拉斯** | `X~B(n,p)` | `(X−np)/√(np(1−p)) →ᵈ N(0,1)`（即正态近似二项分布） |

> **典型题**：用中心极限定理近似求概率 — 标准化后用 Φ 查表

## 第6讲 数理统计

### 三大抽样分布

| 分布 | 定义 | 性质 |
|------|------|------|
| **χ²(n)** | `X₁,…,Xₙ iid N(0,1)`，`χ² = ΣXᵢ²` | `E=n, Var=2n`；可加性 |
| **t(n)** | `T = X / √(Y/n)`，X~N(0,1)，Y~χ²(n)，独立 | 双侧对称，n→∞ 时趋近 N(0,1) |
| **F(n₁,n₂)** | `F = (Y₁/n₁)/(Y₂/n₂)`，Y₁~χ²(n₁)，Y₂~χ²(n₂)，独立 | `1/F ~ F(n₂,n₁)` |

### 正态总体抽样定理（★核心）
- `X̄ ~ N(μ, σ²/n)`
- `(n−1)S²/σ² ~ χ²(n−1)`（且 X̄ 与 S² 独立）
- `(X̄−μ)/(S/√n) ~ t(n−1)`

### 参数估计

| 方法 | 步骤 |
|------|------|
| **矩估计** | 令样本矩 = 总体矩，解方程。如一个参数：`X̄ = E(X)`；两个参数：加 `(1/n)ΣXᵢ² = E(X²)` |
| **最大似然 MLE** | 写似然函数 `L(θ)=Πf(xᵢ\|θ)` → 对数似然 `ln L` → 求导=0 解 θ̂ |

### 估计量评价标准

- **无偏性**：`E(θ̂) = θ`
- **有效性**：无偏前提下 `Var(θ̂)` 越小越有效
- **相合性**：`θ̂ →ᴾ θ`（n→∞）

> **例**：`X_i ~ E(λ)`，λ 的矩估计 `λ̂=1/X̄`；MLE 同样 `λ̂=1/X̄`。但 `1/X̄` 不是 λ 的无偏估计，修正为 `(n−1)/ΣXᵢ`

5. **亚当夏娃公式**：`E(X) = ∫₀^∞ [1−F(x)]dx − ∫₋∞⁰ F(x)dx`（非负时 `E(X)=∫₀^∞ P(X>x)dx`）
